# Project instructions

## Persistent memory

- Before project work, read `brain/index.md` and any linked notes relevant to the task.
- Record durable project knowledge, corrections, and recurring preferences in `brain/`; keep task-specific work in the backlog or plan files.
- When adding or removing brain notes, update `brain/index.md` and the relevant section index.
- Use the `brain`, `reflect`, `plan`, `review`, `ruminate`, and `meditate` skills when their described workflows apply.

## Project workflow

- Follow the project’s existing Angular and TypeScript conventions.
- Use `.noodle.toml` and the Noodle skills for backlog scheduling and implementation workflow.
- Run only the verification relevant to the change and report the commands and results.
